# 도메인 문서

도메인 용어와 설계 결정을 살펴볼 때 다음 문서를 기준으로 삼는다.

## 먼저 읽을 문서

- 용어집은 저장소 루트의 `GLOSSARY.md`를 읽는다.
- 설계 결정은 관련 내용을 다루는 `docs/adr/`의 ADR을 읽는다.

이 저장소는 단일 컨텍스트 구조를 사용한다. 여러 컨텍스트로 나뉘는 경우에는 루트 `GLOSSARY-MAP.md`에서 컨텍스트별 용어집을 찾는다.

## 용어 사용

- 이슈 제목, 테스트 이름, 코드 검토 등에서 도메인 용어집의 정의된 표현을 사용한다.
- 용어집에서 피하도록 지정한 표현은 도메인 개념을 설명할 때 사용하지 않는다.
- 필요한 개념이 용어집에 없으면 기존 용어의 동의어인지 새 개념인지 확인하고, 도메인 모델링 결정에 기록한다.

## ADR 충돌

기존 ADR과 상충하는 제안은 조용히 덮어쓰지 말고, 어떤 ADR과 왜 충돌하는지 명시한다.
