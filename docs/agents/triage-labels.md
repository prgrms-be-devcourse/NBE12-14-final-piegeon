# Triage 라벨

이 저장소는 기본 triage 라벨을 그대로 사용한다.

| 역할 | 라벨 | 의미 |
| --- | --- | --- |
| 초기 분류 필요 | `needs-triage` | 유지 관리자가 검토해야 함 |
| 추가 정보 필요 | `needs-info` | 요청자 답변을 기다림 |
| 에이전트 작업 준비 | `ready-for-agent` | 범위와 요구사항이 명확해 에이전트가 진행할 수 있음 |
| 사람 작업 준비 | `ready-for-human` | 사람이 직접 처리해야 함 |
| 진행하지 않음 | `wontfix` | 처리하지 않기로 결정함 |

스킬이 triage 역할을 언급하면 이 표의 라벨을 사용한다.
