# 이슈 트래커: 로컬 Markdown

이 저장소의 이슈와 명세는 `.scratch/` 아래 Markdown 파일로 관리한다.

## 규칙

- 기능마다 `.scratch/<기능-이름>/` 디렉터리 하나를 사용한다.
- 기능 명세는 `.scratch/<기능-이름>/spec.md`에 작성한다.
- 구현 티켓은 `.scratch/<기능-이름>/issues/<번호>-<이름>.md`에 한 티켓씩 작성하고, 번호는 `01`부터 시작한다.
- 각 티켓 파일 상단에 `Status:`를 두고, triage 상태는 `docs/agents/triage-labels.md`의 기본 라벨 문자열을 사용한다.
- 댓글과 진행 기록은 파일 하단의 `## Comments` 아래에 추가한다.

## 이슈 게시 및 조회

- 이슈 트래커에 게시하라는 요청은 해당 기능 디렉터리에 Markdown 파일을 생성하는 것으로 처리한다.
- 티켓 조회 요청은 사용자가 지정한 경로나 번호에 해당하는 파일을 읽는다.
