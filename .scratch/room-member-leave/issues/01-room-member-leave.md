# 01: 방 나가기

**What to build:** 활동 멤버가 방에서 나갈 때 퇴장 기록과 연관된 설문·안건·장소 상태를 한 트랜잭션으로 갱신하고, 방 활동 내역 및 SSE에 반영한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `DELETE /api/rooms/{roomId}/members/me`를 추가하고 본문 없는 HTTP 200 성공 응답으로 `ROOM_LEFT`, `방에서 나갔습니다.`를 반환한다.
- [ ] 방 행 잠금 후 활동 멤버를 확인하고, 존재하지 않는 방은 404 `ROOM_NOT_FOUND`, 비멤버·나간 멤버는 403 `FORBIDDEN`으로 처리한다. 재요청 멱등 성공은 제공하지 않는다.
- [ ] `leftAt`을 현재 시각으로 기록한다. 마지막 활동 멤버가 퇴장해도 방 상태를 자동 변경하지 않는다.
- [ ] 같은 트랜잭션에서 퇴장 멤버의 설문 응답을 삭제한다. 설문 단계에서는 남은 활동 멤버와 응답으로 명세 5-1 마감 조건을 다시 확인한다.
- [ ] `VOTING` 안건 중 퇴장 멤버에게 자격이 있었던 안건만 처리한다. 투표를 이미 한 멤버의 `Vote`와 `total_voter`는 유지한다. 투표하지 않은 자격자만 `total_voter`에서 빼고, 0이면 `EXPIRED`, 그 외에는 7-1 판정을 다시 수행한다.
- [ ] 퇴장 멤버의 모든 장소 반응을 삭제하고, 후보와 확정 시각은 보존한다. 장소 칸은 남은 활동 멤버 기준으로 다시 계산되게 한다.
- [ ] `MEMBER_LEFT` 방 활동 내역을 같은 트랜잭션에서 저장하고, 커밋 후 `member.left` SSE를 별도 이벤트 이름으로 발행한다. 안건·방 상태 변경용 별도 SSE 이름은 발행하지 않는다.
- [ ] HTTP 통합 테스트 하나에서 인증·권한·퇴장 후 상태 및 방 활동 내역과 `member.left` SSE를 외부에서 검증한다.
- [ ] DB 마이그레이션을 추가하지 않는다.
