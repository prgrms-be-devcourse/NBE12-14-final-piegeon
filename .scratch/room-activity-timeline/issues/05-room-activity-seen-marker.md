# 05: 표시한 활동까지 확인 처리

**Parent:** 01: 방 활동 타임라인과 SSE 공통 전달 구현

**What to build:** 활동 멤버의 확인 시각이 화면에 실제 표시된 활동까지만 전진하고, 이후 활동은 읽지 않은 상태로 남습니다.

**Blocked by:** 03: 활동 타임라인 조회와 초기 동기화

**Status:** ready-for-agent

- [ ] 확인 API는 방 활동 멤버만 사용할 수 있고, 활동 멤버가 아니면 거부된다.
- [ ] 클라이언트는 실제 표시한 마지막 활동의 `createdAt`을 `LocalDateTime` `seenUntil`로 전달한다.
- [ ] 확인 시각은 기존 `last_seen_at`보다 과거로 되돌아가지 않으며 서버 현재 시각으로 대체되지 않는다.
- [ ] 타임라인 조회만으로 확인 시각이 자동 변경되지 않는다.
- [ ] 통합 테스트에서 `seenUntil` 갱신, 단조 증가, 멤버 권한과 조회 시 부수효과가 없음을 확인한다.
- [ ] 변경은 `room`, `room member`와 공통 `changelog` 경계 안으로 제한하고 장소·안건·일정 도메인은 수정하지 않는다.
