# 02: 방별 SSE 실시간 활동 전달

**Parent:** 01: 방 활동 타임라인과 SSE 공통 전달 구현

**What to build:** 활동 멤버가 방에 연결해 새 방 활동을 실시간으로 받을 수 있습니다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 활동 멤버만 방별 SSE 연결을 열 수 있고, 비활성 멤버나 비인증 사용자는 연결할 수 없다.
- [ ] 서버는 구독을 먼저 등록하고 현재 마지막 활동 ID를 기준으로 연결 준비 이벤트를 보낸다.
- [ ] 공통 활동 발행·구독 계약은 트랜잭션 커밋 이후에만 영속 활동을 연결된 방 멤버에게 전달한다.
- [ ] 기존 방 멤버 합류 활동을 첫 실시간 전달 사례로 사용하고, 전달된 이벤트 ID와 본문이 영속 방 활동 기록을 나타낸다.
- [ ] 멤버가 방을 나가면 해당 멤버의 활성 연결을 종료하고 이후 연결을 거부한다.
- [ ] 구현과 검증은 공통 `changelog`, `room`, `room member`, `survey` 경계 안에서 수행한다. 장소·안건·일정 도메인은 수정하지 않는다.
- [ ] 인증 포함 HTTP 통합 테스트에서 연결 준비, 정상 활동 전달, 커밋 전 미전달, 멤버 권한과 연결 종료를 확인한다.
