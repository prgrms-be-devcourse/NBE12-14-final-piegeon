# 03: 활동 타임라인 조회와 초기 동기화

**Parent:** 01: 방 활동 타임라인과 SSE 공통 전달 구현

**What to build:** 활동 멤버가 방에 저장된 활동을 최신순으로 읽고, 최초 조회와 실시간 수신을 한 흐름으로 볼 수 있습니다.

**Blocked by:** 02: 방별 SSE 실시간 활동 전달

**Status:** ready-for-agent

- [ ] 활동 멤버만 해당 방의 활동 타임라인을 조회할 수 있다.
- [ ] 첫 페이지는 최신 활동부터 반환하고, 페이지 크기는 1~100, 기본값은 20이다.
- [ ] 이전 페이지는 마지막으로 받은 ID보다 작은 기록을 반환하며 중복과 누락 없이 이어진다.
- [ ] 초기 타임라인 조회는 일반 최신순 커서 조회를 사용하고 연결 중 수신한 SSE 활동을 ID로 중복 제거해 합친다. 조회 API에는 기준 ID 상한 파라미터를 두지 않는다.
- [ ] 활동 항목은 `logId`, `actor`(시스템은 `null`), 대상 종류·ID, 행위 종류, 저장 당시 요약과 생성 시각을 포함한다.
- [ ] 클라이언트 동기화 계약은 초기 조회가 끝날 때까지 받은 SSE 이벤트를 버퍼링하고 ID로 합쳐 중복을 제거한다.
- [ ] 다른 방의 기록은 조회 결과에 포함되지 않으며 활동 멤버가 아닌 요청은 거부된다.
- [ ] 통합 테스트에서 초기 조회와 SSE 병합, 커서 페이지 연속성, 권한과 방 격리를 확인한다.
